Core Concepts

Client Script

Client Scripts are JavaScript programs that run on the client side. They can dynamically change form behavior when users interact with fields.

UI Policy

UI Policies dynamically control field properties such as mandatory, visible and read-only states without requiring complex scripting.

Incident Form

The Incident form is used to record and manage IT service issues such as problems, requests and system failures.
